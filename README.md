# 🧠 オボエタヨ — 人間らしく忘却するチャットAI

## 🌟 特長

- 🕰️ 記憶は時間で自然に薄れていく（1時間後に50%、1日後に70%減衰）
- 🤖 独り言（セルフトーク）機能あり：5秒間ユーザーが無言だと AI が主観的なひとりごとを呟く
- 😊😐🥱 気分（happy / neutral / tired）に応じて口調・表情・背景が変化
- 🖥️ GUI（PySimpleGUI）／Web（Streamlit）両対応
